# CHOGPIT

A 2D top-down Chog-themed shooter built around **build → raid → scar → rebuild**. Each minted Chog NFT is an arena-owner deed, not a playable fighter: its on-chain token ID and retrievable NFT traits seed the wall routes and terrain (with an explicitly labelled token-ID-only fallback if metadata is unavailable). The current on-chain owner alone can sign and save up to eight defenses; anyone can raid without a wallet or NFT. Server-run solo and 2–4-player private rooms record raids by token ID. The private host visibly chooses PvP or co-op vs bots; each private player has **five lives/four respawns** and three minutes to collect two supplies and extract. Successful raiders can add an acid/static/spores scar that changes later fights. Phone gameplay prompts landscape rotation while portrait menus remain usable.

Arena defenses, counts, five recent raid entries and up to five active gameplay scars persist **on the game host**, keyed by token ID; they do **not** modify the NFT contract or IPFS metadata. `?pit=TOKEN_ID` loads a shareable pit and rechecks its on-chain owner. The current owner is rechecked on every signed save, so transferring the NFT transfers edit rights without clearing the history. The open demo pit is a clearly labelled tutorial. Public, minted examples #1, #2 and #100 are raid targets, **not claimed as owned by the game or the user**. To show builder permissions, a judge must use a token controlled by their own wallet.

## Free Raider Pass demo + proposed CHOG path — neither mainnet mint nor payouts live

The owner proposes **a second NFT for raiders**, alongside existing **official Chog NFT arena-owner deeds**. The lobby can show a clearly labelled *sample Raider Pass* in the browser; this is **not a minted NFT, wallet asset or CHOG entitlement**. [`contracts/ChogpitRaiderPassDraft.sol`](contracts/ChogpitRaiderPassDraft.sol) is an **unreviewed, undeployed** ERC-721 draft for a real free-to-player Monad pass, with later non-spending chain/contract-bound recipient consent, issuer-paid gas, on-chain art, one lifetime mint per wallet and a hard **40-pass** cap. [`tests/raider-pass.mjs`](tests/raider-pass.mjs) uses a **disposable local chain**, not Monad mainnet. **Privy (Developer-tier path)** is selected for the separate [`raider-pass-portal/`](raider-pass-portal/README.md): its **email-only login modal** automatically provisions a user-controlled embedded EVM wallet, with no Connect Wallet/signup wallet signature. The backend verifies Privy’s ES256 identity token, signed email, DID and Privy embedded-wallet association. **No owner Privy App ID, public verification key or allowed origin is configured; no live login/recovery was tested.** Privy publishes a free **0–499-monthly-active-user** tier, which is **not** capped by 40 NFT mints. The portal’s real mint and CHOG endpoints are hard-locked, with no issuer, deployed pass address or reward access. A **separate deliberate claim** would need project-funded MON gas and chain-confirmed ownership. Registration is not an NFT, and this portal is **not in game-only packages**; guests raid and open samples wallet-free. See [`EMBEDDED_WALLET_CLAIM_PLAN.md`](EMBEDDED_WALLET_CLAIM_PLAN.md) and [`RAIDER_PASS_PROTOTYPE.md`](RAIDER_PASS_PROTOTYPE.md).

The prospective real-CHOG rule **replaces** the earlier official-Chog-holder payout condition: **only the raider who opened a box and holds a genuine minted CHOGPIT Raider Pass before payout** could receive CHOG. They do **not** need it before playing or opening; owning an arena Chog NFT alone is not enough for the proposed reward. Nonholders can raid, open sample boxes, leave scars and earn free cosmetics. Earlier proposed economics remain provisional: **two backed opening records per verified email account**, not per person; **40 total NFTs** are a different cap from at most **40** worst-case-backed openings (`40 × 25 = 1,000 CHOG`), 70% 5 / 25% 10 / 5% 25 CHOG. An inbox link, browser sample badge and free pass mint are **not** one-person checks; a person can use multiple wallets/emails, and passes may be transferred. Handling pass-unverified reserved slots is **undecided**. See [`CAMPAIGN_RULES_DRAFT.md`](CAMPAIGN_RULES_DRAFT.md); no public reward terms or payouts are in force.

A raider needs no wallet **to start or open a sample box**. For a future backed opening, the proposed email account would confirm a payout address before batching; before any CHOG transfer the opening raider would need a fresh signed wallet proof of **current ownership of a real on-chain Raider Pass**. A pasted payout address is not holder proof. Unaddressed openings remain pending with original-epoch 25-CHOG backing reserved indefinitely; *pass-unverified* reservation policy is not chosen. Sponsor-paid gas/oracle costs, automatic whole-credit payment at **≥50 CHOG**, sub-50 carry and final-settlement timing remain proposals. **The isolated email candidate and permissionless draft payout vault do not enforce Raider Pass ownership at payment**, so real CHOG remains disabled.
