# CHOGPIT on Cloudflare Free — game only, no CHOG payouts

This is a **separate Cloudflare build** of the full playable shooter. It keeps mobile controls, server solo, private 2–4-player live rooms with host-selected PvP or co-op bot raids, NFT arena ownership checks, owner-signed traps and persistent arena scars. In private rooms each player has **five lives total (four respawns)** and three minutes to collect two supplies and extract. Real CHOG payouts and reward-wallet ledgers are **absent**, not merely hidden. Hidden boxes are non-redeemable samples. A **browser-only sample Raider Pass** can be displayed as a demo, but it is not a real NFT or an application to mint one. If separate mainnet NFT issuance and real-CHOG systems are ever launched, the selected *future* rule pays only the box-opening raider who proves ownership of a genuine minted **CHOGPIT Raider Pass** before payout; the official Chog NFT remains the essential arena deed. The selected future design has a **hard 40-pass cap**: registration would create a user-controlled embedded wallet; only a later deliberate claim would mint a real pass with project-paid gas. **No live registration, wallet creation or claim portal is in this ZIP.** This package implements neither on-chain pass minting nor token payment.

`CHOGPIT_NFT_First_Node_Backup.zip` is for a Node VM. **Do not upload that Node ZIP to Cloudflare.** Use `CHOGPIT_NFT_First_Cloudflare_Update.zip` instead. Neither ZIP contains real-payout code. Cloudflare Workers + one SQLite-backed Durable Object replace Node hosting and its persistent file. Arena edits/raid history survive Worker restarts in the Durable Object's SQLite storage; active matches themselves can be interrupted by a deploy/runtime restart and may need rejoining. This is not a promise of ten-day continuous uptime.

## Free-plan limitations (read before signing up)

Cloudflare advertises Workers Free and SQLite Durable Objects **without a credit card**. At the time this package was prepared, Workers Free offered 100,000 Worker requests/day and 10 ms CPU/request; static-asset requests are free. Durable Objects Free offered 100,000 requests/day, 13,000 GB-seconds/day duration, 5 GB stored data and daily storage-operation limits. **Free limits are hard caps**, not free overage: if exceeded, some requests/operations fail until the daily reset. One room coordinator runs while players have WebSockets open; concurrent play and long-lived sockets use duration allowance. Monitor the Cloudflare dashboard during the event. No free tier offers an uptime guarantee or SLA. Do not upgrade to a paid plan without deciding to pay.

Official terms: https://developers.cloudflare.com/workers/platform/pricing/ and https://developers.cloudflare.com/durable-objects/platform/pricing/ . Worker custom domains: https://developers.cloudflare.com/workers/configuration/routing/custom-domains/ .

## Update the already-live chogpit.tech game — NFT-first, co-op and five lives

This package is configured for the **existing** `chogpit-game` Worker on `chogpit.tech`; it reuses the same Durable Object class/storage, so a successful redeploy should retain stored token-keyed arenas and scars. **The site already showed an earlier NFT-first, no-payout lobby when checked on 19 October, but not this corrected ZIP.** Its #1/#2/#100 NFT reads had fallen back to token-ID-only traits. This ZIP pins those three real IPFS trait snapshots *only after their live Monad `tokenURI` matches an exact content-addressed CID*, tries a second public IPFS gateway for other NFTs and retries transient token-only fallbacks. Local Worker reads recovered the distinct BREACH / SPLIT-LANE / CROSSFIRE routes; production recovery needs an owner redeploy. The lobby makes minted Chog NFTs the arenas: examples #1, #2 and #100 are public raids (not a claim of ownership), and `?pit=ID` opens a shareable pit. Verified metadata traits and token ID seed terrain/wall routes where available; only the current on-chain owner can sign and save defenses. Verified server-run results (total counts and five recent raids) and up to five active scars persist under the token ID on the Worker host, **not on the NFT contract**. Anyone can raid with no wallet. The demo is a separate tutorial.

After a friend joins a private room, the **host** chooses PvP (fight one another) or co-op (fight server-run bots with friendly fire off). The selected mode is visible to all 2–4 players before the host starts and is locked during the countdown/round. In either mode the server gives each player **five lives total: four returns after the first life**, each following a three-second delay and a short spawn-protection period. Supplies held when downed drop onto the map. The three-minute, collect-two-supplies-and-extract objective stays in both modes. Server solo still has one life. No real CHOG can be won.

On phones, the lobby/room/result menus work upright; active play still asks players to turn sideways. Local solo practice waits while the phone rotates. Server-run rooms do **not pause**: controls are neutral in portrait and the round clock continues. The browser cannot reliably force rotation; players may need to disable rotation lock. The landscape HUD, FIRE, DASH and OPEN/HOLD controls fit short screens and safe-area cutouts.

On the owner's Windows computer, download **`CHOGPIT_NFT_First_Cloudflare_Update.zip`** and choose **Extract All** into a new folder. Open PowerShell **inside the extracted folder containing `wrangler.jsonc`** and run these two commands, one at a time:

```powershell
npm.cmd ci
npm.cmd run deploy
```

Your existing Wrangler browser login should be reused. The `wrangler.jsonc` keeps `chogpit.tech` as the Worker Custom Domain and the `workers.dev` backup enabled. If you extract over an old folder where `node_modules` is still intact, `npm.cmd ci` may be skipped, but a fresh folder should run it. A deployment can disconnect active WebSocket rooms; update when friends are **not mid-match**. Check `https://chogpit.tech/healthz` for `GAME_ONLY` and `rewardPayoutsEnabled:false`. Open `https://chogpit.tech/?pit=1`: the NFT dossier should show traits, route, defenses and raid/scar counts, and the primary button should start server solo without a wallet. Compare `?pit=2` and `?pit=100`; an owner-builder demonstration needs a wallet that actually holds the chosen Chog. Then open the game in two windows: create a private room, join with the invite code, have the host pick **FIGHT THE BOTS**, then start; check that both clients see the selection, bots and the five-life HUD. The `workers.dev` backup should remain available. Never paste Wrangler tokens or wallet keys into chat.

**New-account/first-time deployment:** this updated `wrangler.jsonc` specifies the already-active `chogpit.tech` zone. If the zone is not active in a different account, remove the `routes` entry temporarily for the initial `workers.dev` deployment; only restore it after the domain is connected.

## Owner-operated setup (no passwords or wallet keys should be shared)

1. The owner reports buying **`chogpit.tech` directly from Get.Tech**. A public `.tech` registry lookup returned a registered record on 19 October 2026, but public DNS may take time; verify that `chogpit.tech` appears as **Active** in your Get.Tech account and complete any registration-contact verification. Use only `chogpit.tech` for the custom-domain steps in this guide. The game can go live first on `*.workers.dev` without waiting for the new domain's DNS.
2. Create or sign in to a **Cloudflare Free** account at https://dash.cloudflare.com/sign-up . Do not choose Workers Paid. On your **Windows** computer, install Node.js 22+ from https://nodejs.org/ and unzip `CHOGPIT_NFT_First_Cloudflare_Update.zip` into a folder. Open PowerShell **in that extracted folder**.
3. Run `npm.cmd ci`, then `npx.cmd wrangler login` and complete Cloudflare's browser login on **your own machine**. Do not send tokens/passwords to anyone. Run `npm.cmd run deploy`; Wrangler creates one Worker and its SQLite-backed Durable Object. Answer yes if asked to register a `workers.dev` subdomain. Copy the URL it prints, like `https://chogpit-game.YOUR-SUBDOMAIN.workers.dev`.
4. Open `https://.../healthz`; it must return `mode: GAME_ONLY` and `rewardPayoutsEnabled: false`. Open the URL in two browsers or two private windows: create a private room in one, join with the six-character invite code in the other, start a round. The `npm.cmd run test:live -- https://chogpit.tech` command runs API/locked-payout checks and two-client PvP **and co-op** room checks from Windows. It does not edit traps/scars, but closing those test rounds can increment **demo raid/forfeit counters**; use it only when that test data is acceptable. The optional `--local-write-test` switch is for localhost only.
5. **Only after `chogpit.tech` is Active in Get.Tech:** add `chogpit.tech` as a site (Free plan) in Cloudflare; copy the two nameservers **Cloudflare assigns to your zone**. In your **Get.Tech domain control panel**, search for `chogpit.tech`, open **Order Information → Name Servers**, replace the old nameservers with those **two exact Cloudflare nameservers**, then choose **Update Name Servers**. Get.Tech documents this flow at https://get.tech/ (FAQ: “How do I add the name servers or A Records to the domain name?”). Preserve/recreate any important existing email MX/TXT records in Cloudflare. If DNSSEC is enabled at Get.Tech, follow Cloudflare's DNSSEC instructions before changing nameservers. Wait until the zone says **Active** in Cloudflare. This does **not** transfer registrar ownership or require another domain purchase. See https://developers.cloudflare.com/dns/zone-setups/full-setup/setup/ .
6. In Cloudflare **Workers & Pages → chogpit-game → Settings → Domains & Routes → Add → Custom Domain**, add `chogpit.tech`. Cloudflare configures the DNS record and HTTPS certificate. Do not invent an A record or a Cloudflare zone ID. Check `https://chogpit.tech/healthz`, browser game and two-client PvP again. A Worker custom domain requires an active Cloudflare zone; the default `workers.dev` URL works without moving DNS.
7. Monitor **Workers & Pages → Metrics / Durable Objects usage and Errors**, especially request/day, duration/day and storage limits. Do not modify the active Worker during the judging period unless necessary. Export off-platform backups of meaningful arena changes where feasible; free hosting is not a substitute for your own backups. Plan contingencies if load or limits increase.

## Optional local check before deploying

Run `npm ci`, `npm run dev` (localhost port 8787), then in a second terminal `npm run test:live -- http://127.0.0.1:8787 --local-write-test`. The optional write test edits **only your local demo arena**. The game is a single Durable Object; a local Wrangler test is not a real global load test, account verification or proof of Cloudflare uptime. `wrangler dev` keeps its local SQLite state in `.wrangler/state`; do not upload that directory or credentials.

## Safety and operation

- No mainnet Raider Pass contract, issuer-funded mint service, claim accounts, sponsor wallet, private keys, Oracle randomness, real CHOG credits, payout transactions or campaign contract are included. Browser sample passes and box amounts must not be presented as NFT mints or redeemable rewards.
- A passkey or signed reward wallet is **not** required for the free game. The NFT owner may sign an exact arena edit (no spending) only if they want to change that NFT's traps; on-chain owner and CHOG-holder checks still use Monad RPC. Do not provide a seed phrase to any host.
- Live room positions are ephemeral. A Worker deploy/runtime interruption closes sockets and ends active matches. The persisted arena's counters/traps/scars remain in SQLite. A room invite code can be reused only while that room is still live.
- The free plan has hard daily usage limits. If a limit is hit, requests can fail even before **2026-11-02 15:00 UTC**; there is no honest way to guarantee continuous service on an unsponsored free plan. An older **NFT-first, no-payout** Worker was observed live on `chogpit.tech` with *token-ID-only fallback* for all three showcased NFTs and superseded email-only future-reward wording. **The verified-traits and browser-only sample Raider Pass in this ZIP are not live until the owner deploys it.** Its disabled real-mint button must remain disabled after game deployment. The owner must run the update commands above.
