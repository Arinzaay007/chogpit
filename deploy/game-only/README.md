# CHOGPIT — game-only public deployment

**This folder is a deployable source package, not evidence that this update is already live.** It contains the free 2D shooter, minted Chog NFT trait-and-token-seeded wall routes, shareable token pits, signed arena-owner edits and host-side scar history, server-run solo, and private 2–4-player WebSocket rooms with host-selected PvP/co-op and five lives each. Hidden-box numbers and the optional browser-local **sample Raider Pass** are **non-redeemable previews**. The sample badge is not an NFT, cannot become one, and cannot qualify for CHOG. There is **no real Raider Pass contract or mint/claim endpoint, real CHOG campaign, wallet-linked reward balance, passkey signup, claim journal, vault, sponsor, payout worker or token-transfer endpoint** in this package. The separate **future** pass design caps supply at **40**: verified registration would create a user-controlled embedded wallet, and a later deliberate portal claim would trigger a project-paid Monad mint. **This game-only ZIP does not register anyone, create wallets or issue NFTs.** NFT owners may sign an *arena-edit message* with their own wallet; playing never requires a wallet.

## Alternative paid host: one Render Web Service

Render supports public Web Services with managed HTTPS/custom domains [1](https://render.com/docs/web-services) and inbound WebSockets [4](https://render.com/docs/websocket). The included `render.yaml` requests one paid `0.5c-512mb` instance in Frankfurt and a 1 GB persistent disk at `/var/data`; it declares **chogpit.tech** as the custom domain, pins Node 22.22.0, sets `GAME_ONLY_MODE=1`, disables payout settings, and uses `/healthz`. **Review Render's displayed charges before accepting the Blueprint.** Its published base rates are $7/month for this compute plan and $0.25/GB/month for disk, before possible bandwidth or other usage [1](https://render.com/pricing). The region is a starting choice, not a measured latency guarantee. Render's Free tier is unsuitable for keeping arena scars because it sleeps and loses local files on restart [12](https://render.com/docs/free). A persistent disk is single-instance and prevents zero-downtime deployments [9](https://render.com/docs/disks). We therefore disable automatic deploys; schedule manual deployments outside active matches. The Blueprint fields follow Render's reference [2](https://render.com/docs/blueprint-spec), and Node version selection follows its Node guide [1](https://render.com/docs/node-version).

4. Render will give you an HTTPS `*.onrender.com` URL when the deployment succeeds [1](https://render.com/docs/web-services). **No such URL has been created by this package.** Confirm `chogpit.tech` appears under the service's Custom Domains; if the Blueprint did not add it, add it there. Only **after** the service exists, in the authoritative DNS controls for `chogpit.tech` (Get.Tech before a nameserver change, Cloudflare afterward), replace conflicting default parking records for the root and `www` while preserving unrelated email MX/TXT records. Follow the exact values shown by Render: for an apex/root name Render documents an A-record fallback if needed; `www` typically uses a CNAME to your service's real `*.onrender.com` hostname [2](https://render.com/docs/configure-other-dns). Enter the root/apex host in the format your registrar requires (often `@` or blank). A domain purchased moments ago may not yet appear in public DNS; confirm it is active in your registrar account first. Do not guess a service hostname, and do not change nameservers just to point the game. The browser automatically uses same-origin `wss://…/ws` on HTTPS.
5. Verify the deployed URL: `npm ci` and `npm run smoke -- https://YOUR-ACTUAL-HOST` from this folder, or use the equivalent Node commands in `scripts/smoke.mjs`. The smoke test checks the game and WebSocket route and asserts that reward/claim routes remain locked. In two browser windows, create a **private room**, share its invite link, join, start a round and confirm both players move; also test server solo, mobile FIRE, and an NFT arena read if the Monad RPC is reachable. Check `https://YOUR-ACTUAL-HOST/healthz` shows `mode: "GAME_ONLY"` and `/api/campaign/status` shows `ready: false`.

For a local rehearsal on Linux/macOS: `npm ci && NODE_ENV=production DATA_PATH="$PWD/data/arenas.json" npm start`, then `npm run smoke -- http://127.0.0.1:4173`. This local `data/` is ignored by Git; Render must instead use `/var/data/arenas.json` on its attached disk.

## Operating limits

- Arena counters, trap layouts and scars persist in `DATA_PATH`; **active room state is in memory**. A restart or manual deployment disconnects rooms and cannot resume a match. This is a single-instance launch, not horizontally scalable. Schedule downtime, monitor CPU/memory/bandwidth, and inspect logs/health after changes.
- Arrange periodic **off-service backups** of `/var/data/arenas.json` and test restores. Render documents disk snapshots and their limitations [9](https://render.com/docs/disks). If this JSON is corrupt, the server now refuses to start rather than silently overwriting it. Never substitute old preview/reward SQLite data for live-game state.
- Public NFT reads require the Monad RPC and NFT metadata gateway. Those services can fail independently; the demo arena remains available. Rate limits use the direct socket address rather than trusting spoofable forwarded headers; on a shared reverse proxy, heavy NFT lookups can share a limit. Review traffic and abuse controls before a large promotion.
- The arena file stores recent raider display names and match results; publish an appropriate privacy/contact notice and decide how to handle abusive names before broad promotion. Confirm your permission to use the included Chog-themed images/branding. This package makes no claim of official affiliation.
- There is no real CHOG entitlement, wallet credit or prize account in this build. **Never send CHOG/MON to this game or claim that its sample boxes convert to later awards.** A future real-CHOG program would pay only the box-opening raider who proves they hold a **genuine minted CHOGPIT Raider Pass** before payout, **not** the owner of a raided pit. Official Chog NFTs still power the living arenas. The separate pass contract is an unreviewed/undeployed source draft (not shipped in this game-only ZIP); the email-only candidate and existing vault cannot enforce pass ownership. A reviewed, funded reward system and published rules would be needed.
